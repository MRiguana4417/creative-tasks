# Генератор заданий

Бренд, проблема, аудитория, формат, ограничение и метод для креативного упражнения. Для тех, кто умеет придумывать, но не может придумать себе задачу

## Как пользоваться

- Пробел или «Новое задание» перебрасывает всё, кроме закреплённых строк
- Клик по строке перебрасывает только её
- Замок оставляет строку на месте
- Чипы сверху выключают лишние строки
- Записка с раундом запускает таймер
